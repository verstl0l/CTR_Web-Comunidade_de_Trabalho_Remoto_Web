

# CTR_Web-Comunidade_de_Trabalho_Remoto_Web 

## Descrição do Projeto

Esta é a versão **Web** da Plataforma Colaborativa de Trabalho Remoto, estruturada utilizando **Python (Flask)** como backend para gerenciar as rotas, a lógica da aplicação e a conexão com o banco de dados **MySQL**.

## Tecnologias Utilizadas

* **Backend:** Python e Flask.
* **Frontend:** HTML5, CSS3 e Jinja2 (motor de templates do Flask).
* **Banco de Dados:** MySQL.

## Estrutura do Projeto

* `app.py`: Arquivo principal contendo o servidor web e as rotas.
* `templates/index.html`: Página principal da interface web.
* `static/style.css`: Folha de estilos para a interface.
* `README.md`: Documentação do repositório.

## Como Executar o Projeto

1. **Instale as dependências necessárias** abrindo o terminal e executando:
`pip install flask mysql-connector-python`
2. **Configure o Banco de Dados:**
Abra o arquivo `app.py` e insira as credenciais reais de acesso ao seu banco de dados MySQL (usuário, senha e nome do banco).
3. **Execute a aplicação** rodando o comando:
`python app.py`
4. **Acesse no navegador:**
Abra o endereço `[http://127.0.0.1:5000](http://127.0.0.1:5000)` para visualizar o sistema em funcionamento.
